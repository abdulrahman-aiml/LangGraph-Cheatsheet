# 3. Model Routing

One of the most important production concepts.

---

# Problem

Not every request needs GPT-5.

---

Example

User asks:

```text
Translate Hello
```

Using a premium model is wasteful.

---

# Solution

Route requests to different models.

---

Example

```text
Simple Tasks
 ↓
Small Model

Complex Tasks
 ↓
Large Model
```

---

# Router Architecture

```text
Question
 ↓

Router

 ↓

Simple → Cheap Model

Complex → Premium Model
```

---

# Benefits

✅ Lower cost

✅ Faster responses

✅ Better resource utilization

---

# Real Example

```text
FAQ Questions
 → GPT-4o-mini

Research Questions
 → GPT-5

Coding Tasks
 → Claude Opus

Embeddings
 → Embedding Model
```

# 4. Cost Optimization

A critical production skill.

---

# Biggest Cost Driver

```text
Tokens
```

---

Every token:

```text
Input Cost
+
Output Cost
```

---

# Example

Bad

```text
Entire Document
```

sent every request.

---

Good

```text
Relevant Chunks Only
```

---

# Cost Optimization Techniques

### Prompt Optimization

Shorter prompts.

---

### Retrieval Optimization

Less context.

---

### Model Routing

Use smaller models when possible.

---

### Caching

Avoid repeated LLM calls.

---

# Golden Rule

```text
Reduce Tokens
=
Reduce Cost
```

---

# 5. Caching Strategies

One of the easiest optimizations.

---

# Problem

Same question repeated.

---

Example

Users ask:

```text
What is your refund policy?
```

1000 times.

---

Without Cache

```text
1000 LLM Calls
```

---

With Cache

```text
1 LLM Call
999 Cache Hits
```

---

# Cache Architecture

```text
Question
 ↓

Cache?

 ↓

Yes → Return Result

No
 ↓
LLM
 ↓
Store Cache
```

---

# Types of Cache

---

## Response Cache

Stores final answers.

---

## Embedding Cache

Stores embeddings.

---

## Retrieval Cache

Stores retrieved documents.

---

# Benefits

✅ Faster

✅ Cheaper

✅ Lower latency
