# Components of MCP

MCP has two major components:

```text
MCP Client
MCP Server
```

---

# 1. MCP Client

The client is the AI application.

Examples:

* Claude Desktop
* ChatGPT
* Cursor
* Windsurf
* VS Code Extensions
* LangGraph Agents

---

Responsibilities:

```text
Connect
Discover
Call Tools
Read Resources
```

---

# Human Analogy

Restaurant Customer.

The customer requests services.

---

# 2. MCP Server

The server exposes capabilities.

---

Examples:

```text
GitHub MCP Server
Slack MCP Server
Postgres MCP Server
```

---

Responsibilities:

```text
Provide Tools
Provide Resources
Provide Prompts
```

---

# Human Analogy

Restaurant Kitchen.

Provides services requested by customers.

---

MCP Server returns:


---

# Human Analogy

Reading a book.

You consume information.

You don't modify it.

---

# Resource Flow

```text

 ↓

```

---

# 2. Tools

Tools perform actions.

---

Examples

```text

```

---

Example

Agent asks:

```text

```

---

---

# Human Analogy

Using a screwdriver.

You are performing an action.

---

# Tool Flow

```text
Agent
 ↓
Call Tool
 ↓

```

---

# Difference

Resources:

```text
Read Information
```

---

Tools:

```text
Perform Actions
```

---

---

# Discovery Process

One of MCP's most important features.

---

# Traditional Integration

Developer hardcodes:

```text
Available Functions
```

---

# MCP

Client asks:

```text
What tools do you provide?
```

---

Server responds:

```json
{
  "tools": [
    "create_issue",
    "list_issues",
    "search_repositories"
  ]
}
```

---

This makes systems dynamic.

---

# Why Discovery Matters

New tools can appear automatically.

---

Example

GitHub Server adds:

```text
create_pull_request
```

---

Client discovers it automatically.

---

No code changes required.

---

Network communication.

---

Flow

```text

 ↔
```

---

Useful for:

## WebSockets

Real-time communication.

---

Useful for:



---

# MCP

Provides standardized AI access.

---

Example

```text

```

# Comparison

| Feature             | API     | MCP    |
| ------------------- | ------- | ------ |
| Standardized for AI | ❌       | ✅      |
| Tool Discovery      | ❌       | ✅      |

# Common Interview Questions

### What is MCP?

A standardized protocol that enables AI systems to interact with external tools, resources, and prompts.

---

### Why Was MCP Created?

To eliminate custom integrations and standardize AI connectivity.

---

### What are the Core Components?

```text
Client
Server
```

---

### What are MCP Resources?

Read-only data sources exposed to AI systems.

---

### What are MCP Tools?

Executable actions exposed to AI systems.

---

### What are MCP Prompts?

Reusable instruction templates.

---

### MCP vs API?

APIs provide functionality.

MCP provides AI-friendly standardized access to functionality.
