# Common Interview Questions

### What is a Multi-Agent System?

A system where multiple specialized agents collaborate to solve a task.

---

### When Should You Use Multi-Agent Systems?

When task complexity exceeds what a single agent can efficiently handle.

---

### What is a Supervisor Architecture?

A central agent coordinates multiple worker agents.

---

### What is the Planner-Executor Pattern?

One agent plans tasks while another executes them.

---

### What is a Blackboard Architecture?

Agents communicate through shared memory.

---

### Why Use a Reviewer Agent?

To improve output quality and reduce errors.
